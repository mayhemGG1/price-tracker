# Price Tracker

Автоматичний трекер цін для товарів на Rozetka. Скрипт регулярно перевіряє ціну на вказаній сторінці товару, зберігає історію змін у базу даних та надсилає сповіщення в Telegram, якщо ціна опускається нижче заданого порогу.

## Функціонал

- Парсинг назви та ціни товару зі сторінки Rozetka за допомогою Selenium
- Збереження історії цін у SQLite-базі даних
- Порівняння поточної ціни з попередньою перевіркою
- Сповіщення про зниження ціни через Telegram-бота
- Автоматична повторна спроба (retry) при тимчасовій недоступності сайту
- Логування всіх подій у файл та консоль
- Автоматичний запуск за розкладом (щоденна перевірка)

## Технології

- **Python 3.14**
- **Selenium** + **undetected-chromedriver** — обхід виявлення автоматизації
- **SQLite** — зберігання історії цін
- **Telegram Bot API** — сповіщення
- **schedule** — автоматичний запуск за розкладом
- **python-dotenv** — безпечне зберігання секретів
- **pytest** — unit-тестування
- **Docker** — контейнеризація проєкту

## Встановлення

1. Клонуй репозиторій:
```bash
git clone https://github.com/mayhemGG1/price-tracker.git
cd price-tracker
```

2. Встанови залежності:
```bash
pip install -r requirements.txt
```

3. Створи файл `.env` у корені проєкту та додай:
```
TELEGRAM_BOT_TOKEN=твій_токен_бота
TELEGRAM_CHAT_ID=твій_chat_id
```

**Як отримати токен бота:** створи бота через [@BotFather](https://t.me/BotFather) у Telegram.

**Як отримати chat_id:** напиши будь-яке повідомлення своєму боту, а потім скористайся [@userinfobot](https://t.me/userinfobot).

## Налаштування

У файлі `config.py` можна змінити:

```python
PRICE_THRESHOLD = 8000  # поріг ціни для сповіщення
```

У файлі `main.py` вкажи URL товару, який хочеш відстежувати:

```python
url = "https://auto.rozetka.com.ua/ua/твій-товар/"
```

Час автоматичної перевірки задається тут:

```python
schedule.every().day.at("09:00").do(check_price)
```

## Запуск

```bash
python main.py
```

Скрипт запуститься і буде чекати запланованого часу для перевірки ціни. Для постійної роботи залиш термінал відкритим, або запусти скрипт як фоновий процес.

## Запуск через Docker

```bash
docker build -t price-tracker .
docker run --env-file .env price-tracker
```

**Примітка:** через Cloudflare-захист сайту Rozetka, контейнеризований запуск може не проходити перевірку на бота (див. розділ "Відомі обмеження" нижче).

## Тестування

Проєкт містить unit-тести для допоміжних функцій:

## Відомі обмеження

Запуск через Docker-контейнер може стикатись з Cloudflare bot-захистом на 
сайті Rozetka через особливості headless-середовища контейнера. Скрипт 
стабільно працює при локальному запуску (не в контейнері), де 
undetected-chromedriver успішно обходить детекцію автоматизації.

Це відома складність веб-скрапінгу сайтів із серйозним anti-bot захистом — 
повне рішення потребує додаткових інструментів (проксі-сервери, 
спеціалізовані антидетект-рішення), що виходить за межі цього навчального 
проєкту.
